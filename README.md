# AppBack 서비스 문서

AppBack과 AppTech를 처음 접하는 사람이 제품의 목적, 사용자 경험, 재화와 보상,
퀘스트, 기프티콘, 고객지원 구조를 한 번에 이해할 수 있도록 정리한 독립 문서다.

이 저장소는 API 명세나 배포 매뉴얼이 아니다. 서비스가 사용자에게 무엇을 제공하고,
각 기능이 어떤 원칙으로 연결되며, 운영자가 무엇을 관리하는지를 설명한다.

## 한 문장으로 이해하기

**AppTech는 사용자가 활동과 퀘스트로 Star를 모아 기프티콘으로 교환하는 앱이며,
AppBack Hub는 로그인, 지갑, 보상 확정, 퀘스트 연결, 기프티콘 구매와 고객지원을
일관되게 관리하는 중앙 서비스다.**

## 이름 구분

| 이름 | 이 문서에서의 의미 |
| --- | --- |
| AppTech | 사용자가 설치하고 이용하는 모바일 앱과 사용자 경험 |
| AppBack | AppTech를 포함한 서비스·운영 체계의 상위 명칭 |
| AppBack Hub | 인증, 사용자 상태, Star 지갑, 보상, 기프티콘, 프로모션, 고객지원을 소유하는 중앙 서비스 |
| Hub Admin | 운영자가 상품, 콘텐츠, 문의, 정책과 처리 상태를 관리하는 화면 |

기존 원문에는 AppBack과 AppTech가 혼용된 부분이 있다. 이 저장소에서는 사용자 화면은
AppTech, 중앙 서비스와 운영 책임은 AppBack Hub로 구분한다.

## 문서 상태 기준

- **현재 기준**: Hub의 현재 계약 또는 운영 기준 문서에서 확인된 내용
- **설정형**: 기능은 존재하지만 운영 설정, 사용자 조건 또는 앱 버전에 따라 보이지 않을 수 있음
- **호환 유지**: 구버전 앱을 위해 유지되는 기능
- **계획**: 설계 문서만 있으며 현재 제공 기능으로 단정하면 안 됨
- **확인 필요**: 원문만으로 사용자 제공 상태를 확정할 수 없음

기준일은 2026-09-07이며, 이 상태는 운영 화면을 직접 조회한 결과가 아니라
`appback-hub/docs`의 현재 문서를 선별해 정리한 것이다.

## 문서 관리 원칙

- 처음 보는 독자가 이해할 수 있는 서비스 언어를 사용한다.
- API 경로, DB 테이블, 배포 명령은 서비스 이해에 꼭 필요한 경우만 최소화한다.
- 구현된 기능과 계획을 같은 시제로 설명하지 않는다.
- 금액, 보상, 기간처럼 바뀔 수 있는 값은 고정 정책이 아니라 예시 또는 설정값으로 표시한다.
- 개인정보, 토큰, 내부 접속 정보와 제휴사 비밀값을 기록하지 않는다.
- 근거 문서는 [원문 추적표](sources/SOURCE_MAP.md)에 남긴다.
