# 기능 상태표

이 표는 독자가 계획 문서를 현재 서비스로 오해하지 않도록 만든 문서 기준 상태표다.
실제 운영 노출 여부는 사용자 조건, 앱 버전, 운영 설정과 제휴사 상태에 따라 달라질 수 있다.

| 영역 | 기능 | 문서 기준 상태 | 설명 |
| --- | --- | --- | --- |
| 계정 | 소셜 로그인과 사용자 계정 | 현재 기준 | AppTech의 사용자 식별과 Hub 기능 이용의 시작점 |
| 지갑 | Star 잔액과 거래 내역 | 현재 기준 | 보상 적립과 기프티콘 교환의 기준 원장 |
| 지갑 | Gem | 확인 필요 | 지갑 재화로 언급되지만 선별된 서비스 문서만으로 현재 사용자 용도를 확정하지 않음 |
| 보상 | 출석·게임·퀘스트 보상 | 현재 기준 | 활동 조건을 충족하면 Hub가 지급 결과를 관리 |
| 보상 | 미확인 보상함 | 현재 기준 | 일부 이벤트 보상을 사용자가 7일 안에 확인해야 지갑에 지급 |
| 친구초대 | 14일 연속 출석 이벤트 | 설정형 | 활성화 이후 성립한 초대에 적용되며 참여 한도와 만료 규칙이 있음 |
| 퀘스트 | 여러 제휴 적립소 연결 | 현재 기준 | 사용자는 제공사별 퀘스트 화면에서 조건과 보상을 확인하고 참여 |
| 퀘스트 | 보상 버프 | 계획 | 설계 문서가 있으나 현재 상시 제공 기능으로 설명하지 않음 |
| 상점 | Star로 기프티콘 교환 | 현재 기준 | 상품 선택, 본인확인, 구매, 발송·검토, 내역 확인 흐름 |
| 상점 | 기프티콘 타임세일 | 현재 기준 | 기간·수량·할인 조건이 있는 이벤트 상품 |
| 콘텐츠 | 홈·상점·퀘스트 프로모션 | 현재 기준 | 운영자가 배너와 이동 목적지를 관리 |
| 콘텐츠 | 구형 홈 프로모션 | 호환 유지 | 구버전 앱 지원을 위해 유지되는 별도 형식 |
| 콘텐츠 | 앱 공지와 최소 버전 안내 | 현재 기준 | 일반 공지, 업데이트 공지와 앱 버전 정책을 구분해 운영 |
| 콘텐츠 | 인앱 메시지 캠페인 | 계획/확인 필요 | 설계와 앱 연동 문서는 있으나 운영 활성 상태는 별도 확인 필요 |
| 고객지원 | Q&A와 개인 문의 WebView | 현재 기준 | 이메일 대신 앱 안의 Hub 고객지원 화면을 사용 |
| 안전 | 구매 본인확인과 위험 검토 | 현재 기준 | 계정 귀속 확인, 발송번호 확인, 위험도에 따른 자동 발송 또는 검토 |

## 상태 변경 방법

상태를 바꿀 때는 다음 세 가지를 함께 갱신한다.

1. 이 표의 상태와 설명
2. 해당 주제 문서의 문구
3. `sources/SOURCE_MAP.md`의 근거와 확인일

운영 DB나 Admin 화면을 확인하지 않았다면 `현재 운영 중` 대신 `문서 기준 현재 계약`으로 표현한다.
