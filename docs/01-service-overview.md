# 서비스 개요

## AppBack이 해결하는 문제

리워드 앱에서는 로그인, 활동 참여, 제휴사 추적, 보상 확정, 포인트 지갑, 상품 교환과
문의 처리가 서로 끊기기 쉽다. AppBack은 이 흐름을 하나의 사용자 계정과 하나의 보상
원장으로 연결한다.

사용자는 AppTech 앱에서 할 수 있는 활동을 찾고, 참여 조건과 받을 Star를 확인한 뒤
활동한다. 활동 결과가 확인되면 Hub가 보상을 기록한다. 모은 Star는 기프티콘 상점에서
상품으로 교환할 수 있으며, 적립과 구매 내역은 자산 화면에서 확인한다.

## 서비스의 핵심 약속

1. **보상은 Hub가 확정한다.** 앱 화면이나 제휴사 SDK가 보여주는 숫자만으로 Star를
   확정하지 않는다.
2. **거래는 한 번만 반영한다.** 동일한 완료 통지가 반복돼도 중복 적립이나 중복 차감이
   일어나지 않아야 한다.
3. **사용자는 상태를 확인할 수 있다.** 잔액뿐 아니라 보상과 기프티콘 처리 내역을 제공한다.
4. **제휴 활동과 자체 재화를 구분한다.** 퀘스트 수행은 제휴사에서 일어날 수 있지만
   AppTech의 Star 잔액은 Hub 지갑이 기준이다.
5. **민감한 처리는 검증 후 진행한다.** 본인확인과 위험 신호를 이용해 기프티콘 발송과
   계정 오남용을 관리한다.

## 주요 구성요소

| 구성요소 | 역할 |
| --- | --- |
| AppTech 앱 | 가입, 홈, 퀘스트, 자산, 상점, 공지와 고객지원으로 이어지는 사용자 접점 |
| AppBack Hub | 계정, 사용자 상태, Star 지갑, 보상 확정, 상품 교환과 사용자 메시지의 기준 |
| Hub WebView | 상점, 고객지원, 자산 내역처럼 서버 정책과 함께 움직이는 화면 |
| Hub Admin | 상품·프로모션·공지·문의·위험 검토 등 운영자의 관리 접점 |
| 퀘스트 제공사 | 광고, 앱 설치, 참여형 활동, 설문 등 외부 활동과 완료 결과를 제공 |
| 기프티콘 공급사 | 상품 카탈로그와 모바일 쿠폰 발송을 제공 |

## 전체 흐름

```text
가입·로그인
    ↓
홈에서 혜택·퀘스트 발견
    ↓
출석·게임·퀘스트·친구초대 참여
    ↓
Hub가 완료 결과 검증 및 Star 반영
    ↓
자산 화면에서 잔액·리워드 내역 확인
    ↓
기프티콘 선택 → 필요 시 본인확인 → Star 결제
    ↓
즉시 발송 또는 안전 검토 → 쿠폰/처리 내역 확인
```

## 서비스가 아닌 것

- 제휴사 화면에 표시된 포인트를 그대로 보관하는 단순 뷰어가 아니다.
- 모든 광고나 캠페인을 AppBack이 직접 운영하는 것은 아니다.
- 사용자가 보상을 주장하면 수동으로 즉시 지급하는 구조가 아니다.
- 기프티콘 구매를 일반 현금 결제로 처리하는 상점이 아니다. 사용자 지불 수단은 Star다.

## 처음 보는 사람이 기억할 세 가지

- AppTech는 사용자 앱, AppBack Hub는 서비스의 중앙 기록과 정책을 맡는다.
- Star는 활동 보상과 기프티콘 교환을 연결하는 핵심 재화다.
- 외부 제휴사가 활동을 제공하더라도 최종 Star와 구매 상태는 Hub에서 확인한다.
