# 사용자 여정

## 1. 시작하기

사용자는 소셜 로그인으로 계정을 만들거나 기존 계정에 로그인한다. 계정은 이후의
Star 지갑, 활동 내역, 기프티콘과 문의 기록을 묶는 기준이다.

첫 이용 안내는 다음 순서로 서비스를 설명한다.

1. 별을 모아 첫 기프티콘 받기
2. 모은 별을 원하는 상품으로 교환하기
3. 출석과 일일미션으로 매일 별 모으기
4. 원하는 퀘스트를 골라 참여하기
5. 자산 화면에서 리워드와 기프티콘 내역 확인하기

온보딩 화면은 설명용이며 개인 잔액이나 실제 활동 상태를 보여주지 않는다.

## 2. 오늘 할 일 찾기

홈은 사용자가 지금 이용할 수 있는 혜택으로 연결한다. 운영 중인 구성에 따라 다음이
노출될 수 있다.

- 출석 체크
- 일일미션
- 게임 또는 무료 참여 활동
- 퀘스트·오퍼월 적립소
- 친구초대 이벤트
- 기프티콘 할인이나 추천 상품
- 공지와 업데이트 안내

프로모션은 기능 자체가 아니라 해당 기능으로 들어가는 안내 카드다. 카드가 일시적으로
없어도 로그인, 자산 조회와 같은 핵심 기능은 계속 사용할 수 있어야 한다.

## 3. Star 모으기

보상 방식은 두 가지다.

- **즉시 지급**: 활동 결과가 확정되면 Hub 지갑에 바로 반영된다.
- **확인 후 지급**: 이벤트 보상이 미확인 보상함에 도착하고, 사용자가 만료 전에
  확인하면 지갑에 반영된다.

사용자는 앱의 표시만 믿기보다 자산 또는 상태 갱신 후 Hub 지갑의 Star 증가를 확인한다.

## 4. 퀘스트 참여하기

사용자는 퀘스트 화면에서 활동 종류, 참여 조건과 예상 보상을 확인한다. 선택한 적립소에
따라 앱 안 화면, 웹 화면 또는 제휴사 SDK 화면이 열릴 수 있다.

완료 결과는 제휴사가 Hub에 전달하며, Hub는 요청의 유효성과 중복 여부를 확인한 뒤
Star를 반영한다. 제휴사에서 완료했지만 AppTech Star가 늘지 않았다면 먼저 해당 캠페인의
제공사 문의 경로에서 완료 판정을 확인한다.

## 5. 기프티콘 교환하기

사용자는 기프티콘 상점에서 상품과 옵션을 선택하고 Star 가격을 확인한다. 구매 전에는
본인확인 또는 쿠폰 수신번호 확인이 필요할 수 있다.

구매 요청 이후에는 다음 중 하나로 진행된다.

- 안전 조건 충족: 발송 절차를 즉시 시작
- 추가 확인 필요: Star 결제와 요청 내역은 유지하고 운영 검토
- 구매 불가: 차감 전에 중단하거나, 이미 차감된 실패라면 정책에 따라 환불 상태 제공

사용자는 자산 화면의 기프티콘 내역에서 발송·검토·완료·취소와 같은 상태를 확인한다.

## 6. 도움이 필요할 때

앱의 문의사항 메뉴는 Hub 고객지원 WebView를 연다. 기본 화면에는 자주 묻는 문제의
Q&A가 먼저 보이며, 해결되지 않으면 개인 문의를 등록한다. 개인 문의에는 이미지도
첨부할 수 있고, 같은 화면에서 답변과 처리 상태를 확인한다.

캠페인 보상 미지급은 캠페인별 제공사 판정이 먼저다. 제공사에서 지급 완료로 확인됐지만
AppTech Star에 반영되지 않은 경우에 Hub가 자체 원장을 확인한다.

## 예외 상황에서의 사용자 기대

| 상황 | 기대되는 처리 |
| --- | --- |
| 네트워크 오류 | 완료나 실패를 추측하지 않고 상태를 다시 조회 |
| 동일 보상 통지가 반복됨 | Star는 한 번만 지급 |
| 미확인 보상 만료 | 만료 후 수령 불가 |
| 본인확인 도중 앱을 닫음 | 가능한 경우 기존 요청을 재개하고 새 결제를 중복 생성하지 않음 |
| 기프티콘 안전 검토 | 검토 중 상태와 예상 안내 범위를 제공 |
| 알 수 없는 프로모션 이동 | 앱이 중단되지 않고 해당 클릭만 비활성화 |
