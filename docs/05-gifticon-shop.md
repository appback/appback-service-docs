# 기프티콘 상점

## 상점의 역할

기프티콘 상점은 사용자가 모은 Star를 모바일 상품권이나 교환권으로 바꾸는 곳이다.
상품 카탈로그와 발송은 현재 기프티쇼 기반으로 운영하며, 사용자는 공급가가 아니라
AppBack 상점가인 Star 가격을 본다.

## 상품 정보

사용자에게 필요한 정보는 다음과 같다.

- 상품명, 브랜드와 이미지
- 선택 가능한 옵션
- 일반 Star 가격
- 할인 중이라면 기존 가격, 할인 가격과 기간
- 구매 가능 여부
- 구매 후 발송 또는 검토 상태

공급사의 원가, 내부 마진, 비밀 식별값과 원본 응답은 사용자에게 공개하지 않는다.

## 일반 구매 흐름

1. 상품과 옵션을 선택한다.
2. 현재 Star 가격과 구매 가능 상태를 확인한다.
3. 쿠폰을 받을 휴대전화 번호를 확인한다.
4. 필요한 경우 본인확인을 진행한다.
5. 구매 버튼을 눌러 Star 결제 요청을 확정한다.
6. 안전 정책에 따라 즉시 발송 또는 운영 검토로 이동한다.
7. 자산 화면의 기프티콘 내역에서 결과를 확인한다.

연락처 확인이나 본인확인만으로 Star가 차감되지는 않는다. 인증을 마친 뒤 사용자가 구매를
확정해야 실제 구매가 한 번 실행된다.

## 본인확인과 수신번호

기프티콘은 실제 발송 대상이 있는 재화이므로 구매 전 본인확인이 필요할 수 있다.

- 서버가 인증기관의 최종 결과와 전화번호를 직접 확인한다.
- 확인된 신원은 한 계정에 귀속한다.
- 수신번호 변경도 본인확인을 거쳐야 한다.
- 이름, 전화번호와 본인확인 원문을 로그나 사용자 공개 응답에 그대로 남기지 않는다.
- 인증 창을 닫거나 네트워크가 끊긴 것만으로 구매 성공이나 최종 실패를 추측하지 않는다.

## 즉시 발송과 안전 검토

정상 조건을 충족한 구매는 구매 처리 후 바로 발송 절차를 시작한다. 신규 계정, 기기·네트워크
위험 신호 또는 추가 확인이 필요한 거래는 검토 상태가 될 수 있다.

검토는 부정 사용 확정을 뜻하지 않는다. 사용자는 `안전한 발송을 위한 확인 중`과 같이
중립적인 안내를 받아야 한다.

문서 기준 안내 범위:

| 분류 | 사용자 안내 기준 |
| --- | --- |
| 일반 구매 | 자동 발송 조건 충족 시 즉시 발송 절차 시작 |
| 가입 후 48시간 이내 구매 | 별도 추가 위험이 없으면 요청 시각부터 24시간 이내 검토 |
| 단일 의심 신호 | 요청 시각부터 24시간 이내 확인 |
| 복수 확인 항목 | 요청 시각부터 24~48시간 검토 가능 |
| 광고사 확인이 필요한 고위험 건 | 최소 7일, 회신 시점에 따라 더 길어질 수 있음 |

위 시간은 달력 시간이며 발송 보장 시간이 아니다. 실제 문의 답변에서는 구매 요청 시각과
현재 상태를 확인해야 한다.

## 타임세일

타임세일은 특정 상품 옵션을 정해진 기간과 수량 동안 할인된 Star 가격으로 제공한다.

- 시작 전: 프로모션에서 예정 상품으로 안내할 수 있으나 구매는 불가
- 진행 중: 할인 가격과 남은 기간·수량을 기준으로 구매
- 수량 소진: 추가 구매 불가
- 종료 후: 일반 상품 상태로 돌아가거나 노출 종료

동시에 여러 사용자가 마지막 수량을 구매하더라도 한정 수량을 넘겨 판매하지 않는 것이
핵심 원칙이다. 홈 배너의 재고 표시는 늦을 수 있으므로 최종 상태는 상품 상세와 구매 시점의
결과가 기준이다.

## 구매 상태를 읽는 방법

사용자 화면의 표현은 바뀔 수 있지만 의미는 다음과 같이 통일한다.

| 상태 의미 | 설명 |
| --- | --- |
| 처리 중 | 구매 요청을 접수하고 다음 단계를 확인 중 |
| 본인확인 필요 | 결제 전 인증을 완료해야 함 |
| 검토 중 | Star 결제는 기록됐고 발송 전 안전 확인 중 |
| 발송 완료 | 쿠폰 발송 절차가 정상 완료됨 |
| 취소/환불 | 구매가 완료되지 않았고 정책에 따라 Star가 반환됨 |
| 반려 | 검토 결과 발송할 수 없으며 공개 가능한 사유와 후속 상태를 안내 |

사용자는 새 구매를 반복하기 전에 기존 요청의 상태와 내역을 먼저 확인해야 한다.
