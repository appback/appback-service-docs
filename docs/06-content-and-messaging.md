# 프로모션과 사용자 안내

AppTech는 같은 내용을 모든 사용자에게 같은 방식으로 고정 노출하지 않는다. 운영자는
프로모션, 공지, 업데이트 정책과 행동 유도 메시지를 목적에 맞게 구분한다.

## 프로모션

프로모션은 사용자를 특정 기능이나 혜택으로 연결하는 카드다.

대표 위치:

- 홈
- 기프티콘 상점
- 퀘스트·오퍼월 화면

대표 이동 목적:

- 특정 적립소 또는 퀘스트
- 일일미션
- 친구초대
- 기프티콘 상품 상세
- 공지 상세
- 외부 제휴 페이지

프로모션에는 제목, 이미지, 안내 문구, 노출 기간, 순서와 이동 목적이 포함된다. 광고나
외부 제휴 콘텐츠는 사용자가 자체 상품으로 오해하지 않도록 `AD`와 같은 표시를 사용한다.

프로모션은 보조 기능이다. 목록을 받지 못하거나 알 수 없는 이동 목적이 있어도 앱 전체를
막지 않고 해당 영역 또는 클릭만 안전하게 비활성화한다.

## 공지

앱 공지는 사용자가 앱에서 확인해야 하는 서비스 안내다.

- **일반 공지**: 운영 안내, 기능 변경, 장애나 주의사항
- **업데이트 공지**: 새 앱 버전의 주요 변경 내용

공지 목록과 실행 시 팝업은 목적이 다르다. 과거 공지는 히스토리에 남길 수 있지만 실행 시
업데이트 팝업은 현재 유효한 최신 안내가 우선한다.

## 앱 버전 정책

앱 최소 버전 정책은 업데이트 공지와 별개다. 공지를 발행했다고 자동으로 강제 업데이트가
되는 것이 아니며, Android와 iOS의 최소 버전을 각각 운영한다.

최소 버전보다 낮은 앱은 업데이트가 필요하다는 닫을 수 없는 안내를 받을 수 있다. 이 정책은
보안과 호환성을 위한 전체 앱 기준이며, 특정 이벤트 배너의 노출 기간과 혼동하지 않는다.

## 인앱 메시지

인앱 메시지는 특정 사용자나 상황에 행동을 요청하는 모달 또는 배너다. 예를 들어 첫
기프티콘 구매 후 스토어 리뷰를 요청하거나, 주요 기능 사용 후 한 번만 안내할 수 있다.

인앱 메시지는 보상이 아니다. 실제 받을 Star가 없는 메시지를 미확인 보상함에 넣지 않는다.
메시지에는 닫기, URL 열기, 앱 화면 이동과 같은 행동이 연결될 수 있다.

현재 Hub 문서에는 상세 설계와 앱 연동 기준이 있으나 실제 운영 활성 상태는 별도로 확인해야
한다. 따라서 이 저장소에서는 계획/확인 필요 기능으로 분류한다.

## 콘텐츠 운영 원칙

- 사용자가 보는 제목과 설명만으로 무엇을 누르게 되는지 이해할 수 있어야 한다.
- 노출 여부, 순서와 기간을 콘텐츠 설정으로 관리한다.
- 앱에 비밀 키나 제휴사 운영 정보를 넣지 않는다.
- 종료된 이벤트를 현재 혜택처럼 보이게 하지 않는다.
- 가격과 재고처럼 빠르게 변하는 정보는 배너보다 상품 상세의 최신 상태를 우선한다.
- 계획 중인 메시지와 현재 발행된 공지를 같은 상태로 설명하지 않는다.
