# 고객지원과 안전

## 고객지원 채널

AppTech의 기준 고객지원은 이메일이 아니라 앱 안의 Hub WebView다. 사용자는 한 화면에서
자주 묻는 문제를 확인하고, 개인 문의를 등록하며, 답변과 처리 상태를 다시 볼 수 있다.

고객지원 화면은 세 영역으로 구성된다.

| 영역 | 목적 |
| --- | --- |
| Q&A | 광고 ID, 로그인, WebView, 기프티콘, 친구초대 등 자주 묻는 문제를 먼저 해결 |
| 문의 접수 | 기프티콘 상점 또는 기타 개인 문제를 비공개로 등록 |
| 문의 기록 | 내가 등록한 문의의 메시지, 답변과 처리 상태 확인 |

Q&A는 사용자 간 게시판이 아니라 운영자가 관리하는 공개 가이드다. 개인 계정이나 거래가
관련된 내용은 비공개 문의로 처리한다.

## 문의 분류

- **기프티콘 상점 문의**: 상품 교환, 발송, 쿠폰 수령과 구매 상태
- **기타 문의**: 다른 분류에 맞지 않는 개인 문제
- **캠페인 보상 미지급**: Hub 티켓을 바로 열기 전에 해당 캠페인의 제공사 문의 경로에서
  완료 판정을 확인

과거 버전에서 사용한 오퍼월 접속 오류나 제공사 선택 필드는 기존 기록을 이해하기 위해
남을 수 있지만, 현재 신규 문의의 기본 분류는 아니다.

## 문의 상태

| 상태 | 사용자가 이해할 의미 |
| --- | --- |
| 접수 | 문의가 등록됨 |
| 증빙 필요 | 문제 확인에 필요한 추가 화면이나 설명을 요청함 |
| 확인 중 | 운영자가 기록과 상태를 검토 중 |
| 제휴사 확인 중 | 외부 제공사의 판정이나 회신을 기다림 |
| 답변 완료 | 사용자가 확인할 답변이 등록됨 |
| 처리 완료 | 필요한 확인과 조치가 끝남 |
| 반려 | 요청을 처리할 수 없으며 사유를 안내함 |
| 종료 | 더 진행할 내용이 없어 문의를 닫음 |

완료된 문의에 사용자가 새 메시지를 남기면 다시 확인 중으로 전환할 수 있다.

## 첨부와 개인정보

오류나 구매 상태를 설명하기 위해 이미지를 최대 5개까지 첨부할 수 있다. 문서 기준 허용
형식은 JPEG, PNG, WebP이며 파일당 최대 20MB다.

문의에서 받지 말아야 할 정보:

- 주민등록번호와 신분증 전체 이미지
- 카드번호와 결제 비밀번호
- OTP와 계정 비밀번호
- 문제 확인에 필요 없는 전체 개인정보

화면 캡처에는 전화번호, 이름, 잔액, 주문번호와 기기 식별 정보가 포함될 수 있으므로 필요한
부분만 남기고 마스킹한다.

## 안전 정책의 목적

안전 정책은 정상 사용자를 처벌하기 위한 것이 아니라 다음을 막기 위한 장치다.

- 동일 완료 결과의 중복 보상
- 다른 계정이나 다른 수신번호를 이용한 기프티콘 오남용
- 자동화, 변조 기기, 위험 네트워크를 이용한 반복 참여
- 정당한 근거 없이 지급·차감·발송 상태를 변경하는 운영 실수

위험 신호는 검토의 근거이지 그 자체로 부정 사용 확정이 아니다. 최종 반려나 회수는 Hub
원장과 필요한 제휴사 근거를 확인한 뒤 감사 가능한 기록으로 처리한다.

## 고객 답변 원칙

- 확인한 사실과 아직 확인 중인 내용을 구분한다.
- 제공사 판정을 AppTech가 대신 승인할 수 있다고 말하지 않는다.
- 발송 검토 시간을 새 문의 등록 시점부터 다시 계산하지 않는다.
- 공개할 수 없는 위험 탐지 상세나 다른 사용자 정보를 설명하지 않는다.
- 승인, 반려, 환불, Star 지급·차감 같은 운영 조치를 답변 문구만으로 실행하지 않는다.
- AI 답변도 승인된 범위 안에서 안내만 하며 실제 재화나 계정 상태를 바꾸지 않는다.
