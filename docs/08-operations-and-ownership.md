# 운영과 책임

이 문서는 서버 배포 방법이 아니라 서비스를 일관되게 운영하기 위한 책임 구분을 설명한다.

## Hub가 소유하는 것

- 사용자 로그인과 계정에 연결된 서비스 상태
- Star 잔액과 적립·차감·환불·회수 거래
- 퀘스트 실행에 필요한 사용자 문맥과 완료 결과 수신
- 기프티콘 상품 노출, Star 가격, 구매 요청과 처리 내역
- 프로모션, 공지, 앱 버전 정책과 사용자 메시지
- 고객지원 문의, 답변, 상태와 감사 이력
- 위험 신호를 바탕으로 한 기프티콘 발송 검토

## AppTech 앱이 책임지는 것

- 사용자가 이해할 수 있는 화면과 이동 흐름
- Hub가 내려준 잔액, 상태, 콘텐츠와 오류의 정확한 표시
- 퀘스트 완료 후 Hub 상태 새로고침
- 본인확인, WebView와 외부 화면의 안전한 열기·복귀
- 알 수 없는 콘텐츠나 일시적 장애가 앱 전체 오류로 번지지 않게 처리

앱은 Star 지급이나 기프티콘 발송을 로컬에서 확정하지 않는다.

## 운영자가 책임지는 것

- 상품 활성 상태와 사용자 Star 가격 관리
- 타임세일의 기간, 수량과 할인 관리
- 프로모션의 문구, 이미지, 광고 표시, 노출 기간과 이동 목적 관리
- 일반 공지, 업데이트 공지와 최소 앱 버전의 분리 운영
- 문의 답변, 상태 변경과 내부 메모 관리
- 검토 중 기프티콘의 승인·반려 근거 확인
- 변경 결과가 사용자 화면과 내역에 일관되게 보이는지 확인

## 외부 제공사가 책임지는 것

- 캠페인 조건과 참여 화면
- 캠페인 완료 여부의 1차 판정
- 제공사 고유 문의 채널
- 기프티콘 상품 카탈로그 또는 실제 쿠폰 발송

외부 제공사의 내부 운영을 Hub가 대신 소유하지 않는다. Hub는 양쪽 경계에서 필요한
식별, 상태와 결과를 검증하고 AppTech 사용자 경험에 맞게 정리한다.

## 중요한 운영 구분

| 혼동하기 쉬운 항목 | 올바른 구분 |
| --- | --- |
| 업데이트 공지 vs 최소 버전 | 공지는 설명 콘텐츠, 최소 버전은 앱 이용 정책 |
| 프로모션 가격 vs 실제 구매 가격 | 최종 가격은 상품 상세와 구매 시점 기준 |
| 검토 중 vs 부정 확정 | 검토는 확인 단계이며 확정 표현을 사용하지 않음 |
| 제공사 지급 완료 vs AppTech Star | 제공사 완료 후 Hub 지갑 반영까지 확인 |
| 본인확인 vs 구매 | 인증만으로 Star를 차감하거나 상품을 발송하지 않음 |
| Q&A vs 개인 문의 | Q&A는 공개 가이드, 개인 거래 문제는 비공개 티켓 |

## 서비스 변경 시 문서 체크리스트

서비스 정책이나 화면이 바뀌면 다음 질문에 답한다.

1. 사용자는 무엇이 달라졌는가?
2. Star, 구매 또는 개인정보에 영향을 주는가?
3. 현재 제공 기능인가, 설정형 기능인가, 계획인가?
4. 구버전 사용자는 무엇을 보게 되는가?
5. 고객지원은 어떤 상태와 근거를 확인해야 하는가?
6. 외부 제공사와 Hub 중 누가 최종 판단을 소유하는가?
7. 숫자와 기간은 고정 정책인가, 변경 가능한 운영값인가?

답을 이 저장소의 해당 주제 문서와 기능 상태표에 반영한다.
