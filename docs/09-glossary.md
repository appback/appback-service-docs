# 용어집

| 용어 | 뜻 |
| --- | --- |
| AppBack | AppTech 사용자 경험과 이를 뒷받침하는 Hub·운영 체계를 포괄하는 서비스 명칭 |
| AppTech | 사용자가 활동하고 Star를 모아 상품으로 교환하는 모바일 앱 |
| Hub | 계정, 지갑, 보상, 상품, 콘텐츠와 고객지원의 중앙 기준 서비스 |
| Hub Admin | 운영자가 Hub의 상품, 콘텐츠, 문의와 정책을 관리하는 화면 |
| Star | AppTech 활동 보상과 기프티콘 구매에 사용하는 핵심 재화 |
| Gem | Hub 지갑에 언급된 별도 재화. 현재 사용자 용도는 추가 확인 필요 |
| 지갑 | Star 같은 재화의 잔액과 모든 증감 거래를 관리하는 기능 |
| 원장 | 언제, 왜, 얼마가 적립·차감·환불됐는지 남긴 기준 기록 |
| 퀘스트 | 사용자가 조건을 확인하고 수행해 보상을 받을 수 있는 활동 |
| 오퍼월 | 여러 광고·설치·참여·설문형 퀘스트를 모아 보여주는 목록 또는 화면 |
| 제공사/Provider | 퀘스트 목록, 참여 화면이나 완료 판정을 제공하는 외부 파트너 |
| Callback/Postback | 제공사가 활동 완료 결과를 Hub에 전달하는 서버 간 통지 |
| 미확인 보상 | 사용자가 만료 전에 확인해야 실제 지갑에 지급되는 이벤트 보상 |
| 기프티콘 | Star로 교환해 휴대전화 등으로 받는 모바일 상품권 또는 교환권 |
| 타임세일 | 특정 상품을 정해진 기간·수량 동안 할인된 Star 가격으로 판매하는 이벤트 |
| 본인확인 | 구매자와 계정의 신원을 인증기관 결과로 확인하는 절차 |
| WebView | 앱 안에서 Hub가 제공하는 웹 화면을 여는 방식. 상점·고객지원·자산 내역 등에 사용 |
| 프로모션 | 홈, 상점, 퀘스트 화면에서 특정 혜택이나 기능으로 연결하는 운영 콘텐츠 |
| 공지 | 일반 안내 또는 앱 업데이트 내용을 전달하는 콘텐츠 |
| 최소 버전 | 계속 사용하기 위해 필요한 Android 또는 iOS 앱의 최저 버전 정책 |
| 인앱 메시지 | 특정 상황에서 행동을 안내하는 모달 또는 배너. 보상과는 별개 |
| 검토 | 기프티콘 발송 등 민감한 처리를 확정하기 전에 추가 근거를 확인하는 상태 |
| 멱등성 | 같은 완료나 구매 요청이 반복돼도 결과를 한 번만 반영하는 성질 |
| 호환 유지 | 구버전 앱이 계속 동작하도록 이전 계약을 일정 기간 유지하는 것 |
