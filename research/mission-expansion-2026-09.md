# 미션 유형 확장 조사: 영상·오디오·생활형 리워드

> 조사일: 2026-09-07
>
> 목적: 게임, 참여형 캠페인, 설문 외에 AppTech에 적용할 수 있는 리워드 미션 탐색
>
> 성격: 시장 조사와 제품 제안. 현재 제공 기능이나 구현 확정안이 아니다.

## 결론

추가할 만한 미션은 충분히 있다. AppBack에 가장 적합한 순서는 다음과 같다.

1. **전문 영상 학습 미션**: 계약된 영상 시청 후 짧은 이해도 문항에 답하면 보상
2. **오디오·팟캐스트 청취 미션**: 계약된 음원·방송을 일정 시간 듣고 체크포인트 수행
3. **읽기·학습 미션**: 기사, 금융·보험·건강 안내를 읽고 퀴즈 완료
4. **영수증·구매 인증 미션**: 특정 상품 구매를 영수증이나 주문 연동으로 확인
5. **걷기·생활습관 미션**: 걸음, 운동, 수면 등 일상 행동을 일일 한도 안에서 보상
6. **방문·현장 미션**: 매장 방문 후 QR, NFC 또는 위치와 영수증을 조합해 확인
7. **콘텐츠 제작 미션**: 후기, 사진, 숏폼 등 결과물을 제출하고 검수 후 보상

첫 실험은 `영상 재생시간만 채우면 보상`보다 **5~10분 전문 콘텐츠 + 2~3개 이해도
문항 + 1회성 Star 지급**이 적합하다. 광고주에게도 단순 조회수보다 `끝까지 보고 핵심
내용을 이해한 사용자`라는 결과를 제공할 수 있고, 무음·백그라운드 재생 어뷰징도 줄일 수 있다.

라디오는 가능하지만 첫 단계에서 `백그라운드로 몇 시간 켜두기`를 보상하는 방식은 권하지
않는다. **5~15분 스폰서 오디오 또는 팟캐스트 + 중간 체크포인트 + 마지막 한 문항**으로
검증 가능한 청취 미션부터 시작하는 편이 낫다.

## 현재 캠페인 분류와 빈 영역

| 현재 분류 | 대표 행동 | 강점 | 빈 영역 |
| --- | --- | --- | --- |
| 게임 | 설치, 플레이, 레벨·과업 달성 | 체류시간과 반복 참여 | 비게임 사용자의 접근성 |
| 참여 미션 | 앱 설치, 바이럴, 금융, 보험 등 | 광고주 전환과 직접 연결 | 짧고 가벼운 일상 참여 |
| 설문 | 질문 응답, 패널 조사 | 의견 데이터 확보 | 수동 응답 피로와 이탈 |

새로운 축은 `콘텐츠 소비`, `일상 행동`, `오프라인 증빙`, `사용자 제작`이다. 기존 참여형
미션 안에 기술적으로 포함할 수 있지만, 사용자가 기대하는 행동과 광고주가 구매하는 결과가
다르므로 서비스 화면에서는 별도 카테고리로 구분할 가치가 있다.

## 시장에서 확인되는 모델

### 1. TikTok Lite: 자체 콘텐츠 참여 보상

한국·일본용 TikTok Lite는 18세 이상 사용자를 위한 자체 Task 페이지와 포인트 기능을
운영한다. TikTok 공식 도움말은 콘텐츠 탐색, 좋아요, 팔로우, 기간 한정 작업, 추천과
체크인으로 포인트를 받을 수 있다고 설명한다. 한국 Google Play 설명에는 시청으로 쌓은
포인트를 기프티콘 또는 현금으로 교환할 수 있다고 적혀 있다.

중요한 점은 TikTok이 **자기 플랫폼 안에서 자기 콘텐츠, 사용자 계정, 재생 세션과 보상
정책을 함께 소유한다**는 것이다. 이 사례는 시청 보상의 수요를 입증하지만, 제3자인 AppBack이
TikTok 영상을 재생시켜 외부 조회수를 만들고 Star를 주어도 된다는 근거는 아니다.

공식 자료:

- [TikTok Lite 공식 도움말](https://support.tiktok.com/ko/using-tiktok/exploring-videos/tiktok-lite-app)
- [TikTok Lite 일본·한국 서비스 설명](https://ads-useast2a.tiktok.com/resources/help/article/about-tiktok-lite-japan-and-korea?lang=en)
- [한국 Google Play의 TikTok Lite](https://play.google.com/store/apps/details?gl=kr&hl=ko&id=com.ss.android.ugc.tiktok.lite)

### 2. Mode: 음악·영상·뉴스를 묶은 수동·수동형 보상

Mode는 음악 청취, 짧은 보상형 영상, 뉴스, 게임, 설문과 오퍼를 한 앱에서 제공한다.
공식 도움말은 음악 재생 중 수동으로 포인트를 쌓을 수 있고, 영상은 짧은 광고 시청 보상이라고
구분한다. 이는 여러 미션 유형을 한 지갑에 합치는 모델이 가능하다는 사례다.

- [Mode의 포인트 획득 방법](https://helpdesk.modemobile.com/hc/en-us/articles/31058175092116-How-to-Earn-Points-with-Your-Mode-Earn-Phone)

### 3. Fountain: 팟캐스트 청취 보상

Fountain은 매일 첫 1시간의 팟캐스트 청취와 프로모션 청취에 보상을 제공한다. 청취자가
클립을 만들고 다른 사용자가 반응하면 추가 보상을 받는 구조도 소개한다. 단순 청취를 넘어
콘텐츠 발견과 제작자 생태계를 묶은 사례다.

- [Fountain 소개](https://blog.fountain.fm/about)

### 4. Media Rewards: 라디오·TV 노출 측정 패널

Media Rewards는 앱을 백그라운드에 두고 주변의 TV, YouTube, 라디오 광고 노출을 자동
측정하도록 허용한 사용자에게 포인트와 추첨 기회를 제공한다. 이는 `라디오를 듣고 보상`하는
사례처럼 보이지만 실제 사업은 **미디어 소비 보상보다 광고 노출 측정 패널**에 가깝다.

이 모델을 모방하려면 마이크와 백그라운드 측정, 오디오 지문, 명확한 동의, 데이터 보존과
철회 절차가 필요하다. 일반 청취 미션보다 개인정보·스토어 심사 부담이 훨씬 크다.

- [Media Rewards 공식 설명](https://mediarewards.zendesk.com/hc/en-us/articles/360018478038-What-is-Media-Rewards)

### 5. Zogo: 학습 후 보상

Zogo는 앱 안의 학습 콘텐츠와 커뮤니티 활동 완료로 코인을 지급하고, 이를 기프트카드 등으로
교환하게 한다. 전문 지식을 작은 단위로 학습하고 보상하는 `learn-to-earn` 사례다.

- [Zogo 코인 정책](https://zogofinancesupport.zendesk.com/hc/en-us/articles/8608297141275-Coins)

### 6. Evidation: 건강 행동 보상

Evidation은 걷기, 운동, 수면, 영양과 건강 체크인, 설문, 기사 읽기 등에 포인트를 지급한다.
연동 건강 앱의 데이터와 앱 안의 카드 활동을 결합한다.

- [Evidation 포인트 방식](https://help.evidation.com/hc/en-us/articles/360008058913-How-does-our-point-system-work)
- [Evidation 서비스 흐름](https://evidation.com/how-it-works)

### 7. Fetch: 영수증과 구매 보상

Fetch는 종이 영수증 촬영, 전자 영수증 연동, 특정 브랜드 구매와 게임 참여에 포인트를
지급한다. 영수증 중복, 오래된 영수증과 허위 영수증을 별도로 통제한다. 광고주는 실제
구매 데이터를 얻고 사용자는 평소 구매를 보상받는 구조다.

- [Fetch 포인트 획득 방법](https://help.fetch.com/hc/en-us/articles/115015863848-How-to-Earn-Points-on-Fetch)
- [Fetch 영수증 정책](https://fetch.com/faq)

## 추천 1: 전문 영상 학습 미션

### 적합한 콘텐츠

- 금융상품 가입 전 기본 개념과 위험 안내
- 보험 보장 항목과 청구 방법 설명
- 건강·안전·공공 캠페인
- 브랜드 신제품 사용법
- 취업·직무·디지털 교육
- 앱 기능 튜토리얼과 신규 서비스 소개

금융·보험 영상은 광고성 콘텐츠와 의무 고지를 명확히 구분해야 하며, `보상 때문에 봤다`는
사실이 상품 적합성 확인이나 가입 동의로 오인되지 않게 해야 한다.

### 권장 완료 조건

```text
미션 열기
  → 보상·예상 시간·광고성 여부 확인
  → AppBack이 계약한 플레이어에서 영상 재생
  → 활성 화면으로 전체 길이의 80~90% 이상 시청
  → 영상 중 1회 무작위 체크포인트
  → 종료 후 핵심 문항 2~3개 중 기준 점수 통과
  → Hub가 1회성 완료와 Star 지급 확정
```

시간만 채우지 않고 이해도 문항을 넣으면 광고주에게 `검증된 학습 완료`를 판매할 수 있다.
정답을 여러 번 무제한 시도하게 하면 형식적 완료가 되므로 문항 풀, 재시도 대기와 일일 한도를
함께 둔다.

### 수집할 최소 증거

- 캠페인·콘텐츠 버전
- 서버가 발급한 재생 세션
- 실제 재생 구간과 누적 활성 시간
- 일시정지, 탐색, 배속과 화면 가시성
- 체크포인트 응답과 최종 문항 결과
- 사용자·기기별 1회 완료 키

얼굴 영상, 시선 추적이나 상시 카메라를 이용한 `실제 시청 인증`은 첫 버전에서 제외한다.
효과에 비해 민감도와 거부감이 크다.

## 추천 2: 오디오·라디오 미션

### 현실적인 첫 모델

`아무 라디오나 몇 시간 켜두면 지급`이 아니라 아래처럼 캠페인 단위로 운영한다.

- 5~15분 스폰서 오디오
- 전문 팟캐스트의 특정 구간
- 브랜드 인터뷰 또는 제품 사용 설명
- 공공·안전 안내 방송
- 라이브 방송 중 특정 시각 체크인

완료는 재생 heartbeat만 보지 않고 중간에 들은 키워드 선택, 마지막 한 문항 또는 라이브
코드 입력을 조합한다. 화면을 끈 백그라운드 재생은 허용할 수 있지만 음량 0, 비정상 배속,
동시 다중 재생과 반복 완료를 제한한다.

### 일반 인터넷 라디오가 어려운 이유

1. 청취 시간만으로 실제 집중을 증명하기 어렵다.
2. 음악·방송 재송출과 광고 삽입에는 권리 계약이 필요하다.
3. 외부 스트리밍 서비스의 재생수를 보상으로 늘리면 인위적 스트리밍이 될 수 있다.
4. 백그라운드 장시간 재생은 배터리·데이터 사용과 사용자 불만을 만든다.
5. 낮은 광고 단가만으로 Star와 기프티콘 비용을 충당하기 어려울 수 있다.

Spotify는 제3자가 청취에 금전적 인센티브를 제공하는 제안을 사기 위험으로 안내하고,
보장된 스트림을 판매하는 서비스가 약관을 위반한다고 명시한다. 따라서 Spotify나 다른
음악 플랫폼의 재생수를 늘리는 미션은 공식 계약 없이는 진행하지 않는다.

- [Spotify의 청취 금전 인센티브 안내](https://support.spotify.com/br-en/article/supposed-financial-incentives/)
- [Spotify의 인위적 스트리밍 정책](https://support.spotify.com/is-en/artists/article/third-party-services-that-guarantee-streams/)

## TikTok·YouTube 영상을 이용할 때의 경계

### 가능한 방향

- 광고주가 권리를 보유한 원본 영상을 AppBack 전용 플레이어로 제공
- 플랫폼과 정식 파트너 계약을 맺고 허용된 측정 이벤트만 보상
- 외부 조회수와 무관하게 AppBack 안의 학습 완료만 별도 집계
- 사용자가 영상을 본 뒤 AppBack 문항을 풀고, 보상은 그 문항 결과에 지급

### 피해야 할 방향

- TikTok·YouTube 영상 조회수 자체를 대가로 Star 지급
- 좋아요, 팔로우, 댓글, 구독을 보상 조건으로 강제
- 여러 기기·계정으로 재생 수를 늘리는 구조
- 자동재생, 숨김 WebView, 무음 반복 재생
- 플랫폼 화면을 흉내 내거나 공개 숫자를 완료 증거로 사용

YouTube는 금전적 이득이 주목적인 참여와 제3자의 인센티브 트래픽을 가짜 참여 또는 무효
트래픽으로 볼 수 있다고 명시한다. TikTok Lite의 자체 리워드는 TikTok 생태계 내부 정책이므로
AppBack의 제3자 보상 권한으로 해석하면 안 된다.

- [YouTube 가짜 참여 정책](https://support.google.com/youtube/answer/3399767?hl=en-eu)
- [YouTube 무효 트래픽 안내](https://support.google.com/youtube/answer/10285842?hl=en-EN)

## 광고 네트워크와 앱 심사 주의사항

Google AdMob의 보상형 광고 정책은 현금, 암호화폐와 기프트카드 같은 직접 금전성 보상을
허용하지 않는다. 간접 보상도 동일 사용자가 게시자 플랫폼 안에서만 사용하고 제3자에게
이전할 수 없어야 한다는 제한이 있다. Star는 기프티콘으로 교환되므로 일반 AdMob 보상형
광고 수익을 그대로 Star 재원으로 삼는 구조는 사전 서면 확인 없이 진행하면 위험하다.

전문 영상 미션은 일반 광고 네트워크의 보상형 영상과 분리해, 광고주와 직접 계약한 콘텐츠
캠페인 또는 해당 보상 구조를 명시적으로 허용하는 파트너 상품으로 운영해야 한다.

- [Google AdMob 보상형 광고 정책](https://support.google.com/admob/answer/7313578?hl=en)

Apple은 광고 노출·클릭을 인위적으로 늘리는 앱과 광고 표시가 주목적인 앱을 허용하지 않으며,
Google Play도 의미 있는 기능과 사용자 경험을 요구한다. AppTech 전체가 `광고를 틀어두는 앱`으로
보이지 않도록 학습, 자산, 퀘스트, 상점과 고객지원이라는 실제 효용 안에서 미션을 제공해야 한다.

- [Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)
- [Google Play 기능·콘텐츠 정책](https://support.google.com/googleplay/android-developer/answer/9898783?hl=en)
- [Google Play 광고 정책](https://support.google.com/googleplay/android-developer/answer/9857753?hl=en-GB)

### 제휴 신청 전에 보낼 공통 질문

1. 대한민국 트래픽을 받는지, 월간 최소 사용자·노출 조건과 예상 공급량은 얼마인지
2. Android와 iOS를 모두 지원하며 비게임 리워드 앱도 승인하는지
3. 기프티콘으로 전환 가능한 `Star` 지급을 허용하는지
4. 서버 간 완료 콜백, 서명 검증, 멱등 키, 취소·차감 콜백을 제공하는지
5. 부정 참여 판정, 광고주 미승인, 지급 취소와 사용자 이의 제기 책임이 누구에게 있는지
6. 정산 통화·주기·최소 금액, 세금, 환율과 보상 원가를 포함한 예상 순마진은 얼마인지
7. 국외 이전을 포함해 어떤 개인정보·광고 식별자를 수집하고 보관·삭제하는지
8. 오디오의 경우 백그라운드 재생, 음량 감지와 콘텐츠 권리를 어떻게 처리하는지

신청서에는 `광고를 켜두면 현금성 보상을 주는 앱`이 아니라, AppBack의 캠페인 유형,
완료 검증, 일일 한도, 부정 방지와 Star 교환 구조를 정확히 설명한다. 업체의 서면 허용을
받기 전에는 SDK를 운영 환경에 넣거나 사용자에게 해당 미션을 노출하지 않는다.

## 1차 도입 우선순위

### A. 바로 검토: 영상 학습형

- 콘텐츠: 5~10분, 광고주가 권리를 보유한 MP4/HLS
- 검증: 활성 재생률 + 무작위 체크포인트 + 2~3문항
- 보상: 사용자·콘텐츠 버전당 1회
- 과금: 검증 완료당 비용(CPCV) 또는 캠페인 예산
- 장점: 기존 Hub의 캠페인·멱등 지급 모델과 잘 맞음

### B. 소규모 실험: 오디오 학습형

- 콘텐츠: 5~15분 스폰서 오디오 또는 팟캐스트
- 검증: 재생 heartbeat + 중간 키워드 + 마지막 문항
- 보상: 일일 한도와 동일 콘텐츠 반복 제한
- 과금: 검증 청취 완료당 비용
- 조건: 콘텐츠 사용권과 백그라운드 재생 정책 확보

### C. 파트너 확보 후: 영수증·구매 인증

- 광고주가 특정 상품과 보상 예산을 제공
- OCR만 믿지 않고 중복, 날짜, 매장, 상품, 반품을 확인
- 영수증 이미지 보존 기간과 개인정보 마스킹 정책 필요

### D. 별도 개인정보 검토 후: 걷기·생활습관

- 일일 걸음 구간과 연속 달성 위주로 작은 보상
- Health Connect 등 사용자가 통제할 수 있는 표준 연결 사용
- 수동 입력값을 재화 지급 근거로 사용하지 않음
- 건강·피트니스 데이터의 수집 목적, 권한과 삭제 경로 고지

Android는 건강·피트니스 데이터 사용과 권한을 별도로 선언하고, 사용자가 접근을 중단하거나
관리할 수 있는 화면을 제공하도록 안내한다.

- [Android Health Connect 시작 가이드](https://developer.android.com/health-and-fitness/health-connect/get-started)
- [Health Connect 권한과 데이터 접근](https://developer.android.com/health-and-fitness/health-connect/ui/permissions)

## 영상·오디오 미션의 최소 제품

### 사용자 화면

- `영상 학습`, `오디오 학습` 별도 카테고리
- 시작 전 예상 소요시간, Star, 광고·협찬 여부, 완료 조건 표시
- 재생 중 진행률과 체크포인트
- 완료 후 문항, 통과·재시도·지급 결과
- 자산 내역에 콘텐츠명과 보상 이유 표시

### 캠페인 설정

- 콘텐츠 ID와 버전
- 제공자와 사용권 종료일
- 시작·종료 시각, 총 예산, 사용자별·일일 한도
- 최소 활성 재생 비율과 허용 배속
- 체크포인트와 문항 풀
- 통과 점수, 재시도 횟수와 대기시간
- 완료당 Star와 중복 지급 키

### 부정 방지

- 서버 발급 일회성 세션
- 짧은 주기의 서명된 진행 heartbeat
- foreground/background, 음량, 배속과 탐색 기록
- 한 계정의 동시 재생 제한
- 기기·계정·네트워크 이상 패턴 관측
- 문항과 선택지 순서 섞기
- 완료와 Star 지급의 단일 멱등 키

부정 신호 하나만으로 사용자를 확정 차단하지 않는다. 보상 거부, 검토와 최종 부정 확정을
구분하고 사용자에게는 공개 가능한 이유만 안내한다.

## 사업성 판단 지표

파일럿은 조회수보다 아래 지표로 판단한다.

| 영역 | 지표 |
| --- | --- |
| 참여 | 노출→시작률, 시작→완주율, 평균 활성 재생률 |
| 이해 | 문항 1차 통과율, 오답 분포, 콘텐츠별 이탈 지점 |
| 품질 | 비정상 배속률, 무음·백그라운드 비율, 중복·동시 세션률 |
| 재무 | 광고주 완료 단가, 사용자 Star 원가, 공급·운영비, 부정 차감 후 마진 |
| 유지 | 다음 날·7일 재방문, 다른 미션과 상점 이용 전환 |
| 신뢰 | 미지급 문의율, 검토율, 광고 숨김·신고율 |

최소 손익 조건은 다음처럼 잡는다.

```text
검증 완료당 광고주 수익
  > 지급 Star의 실제 기프티콘 원가
  + 콘텐츠 전송·측정 비용
  + 제휴·운영·고객지원 비용
  + 부정 참여 손실 충당분
```

일반 광고 CPM만으로 이 조건을 맞춘다고 가정하지 않는다. 파일럿 전에 광고주가 `검증된
완주·이해`에 지불할 단가를 먼저 확보해야 한다.

## 최종 제안

AppBack의 네 번째 캠페인 축을 **`콘텐츠 학습 미션`**으로 정의하는 것이 좋다. 그 아래에
`영상`, `오디오`, `읽기` 형식을 둔다.

첫 상품은 `전문 영상 5~10분 시청 + 핵심 문항 통과`로 만들고, 두 번째로 `스폰서 오디오
5~15분 청취 + 체크포인트`를 시험한다. TikTok·YouTube·Spotify의 외부 조회수나 스트림 수를
보상하는 모델은 공식 파트너 계약 전까지 제외한다.

이 방향은 사용자가 단순히 광고를 켜두는 앱이 아니라, 유용한 콘텐츠를 선택해 배우고 그
시간과 이해에 대해 보상받는 서비스로 AppTech를 확장한다.
